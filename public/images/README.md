# 画像素材について

架空店舗「美容室 いろどり坂」用の写真です。Geminiで生成した画像に差し替え済みで、4サンプル共通で使っています。

| ファイル名 | 用途 | 備考 |
| --- | --- | --- |
| `hero-bg.jpeg` | トップのヒーロー背景 | モデルのポートレート |
| `interior.png` | コンセプト欄の店内写真 | セット面・シャンプー台 |
| `menu-cut.png` | メニュー「カット」 | |
| `menu-color.jpeg` | メニュー「カラー」 | |
| `menu-perm.png` | メニュー「パーマ」 | |
| `menu-treatment.png` | メニュー「トリートメント」 | |
| `menu-straight.png` | メニュー「縮毛矯正」 | ⚠️ゆるめのウェーブ写真を仮で使用中。ポーカーストレートの写真に差し替えるとより違和感がなくなります |
| `menu-headspa.png` | メニュー「ヘッドスパ」 | ⚠️ヘアスタイル写真を仮で使用中。頭皮マッサージ・リラックスシーンの写真に差し替え推奨 |
| `staff-1.png` | スタッフ「佐倉 美月(店長)」 | |
| `staff-2.png` | スタッフ「遠野 蒼」 | |
| `exterior.png` | (未使用・予備) | 外観・入口の写真。現状どのページにも組み込んでいません。アクセス欄などに追加したい場合は声がけください |

SNSアイコン(Instagram/X)はHTML内に直接インラインSVGで埋め込んでいるため、このフォルダに画像ファイルはありません。ブランドロゴを使う場合は各HTML内の `<svg class="icon-sns">` 部分を差し替えてください。
