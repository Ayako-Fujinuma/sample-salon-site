# 画像素材について

架空店舗「美容室 いろどり坂」用の写真です。現在は全ファイル、内容がひと目でわかる**仮画像(SVGのグラデーション+ラベル)**になっています。4サンプル共通で使っています。

Geminiで写真を生成して差し替える際は、**同じファイル名(拡張子は`.svg`→`.jpg`に変更)**で置き換えてください。ファイル名を変える場合は、各HTML/CSS内の該当 `src` / `background-image` も合わせて書き換える必要があります(このチャットで画像を渡していただければ、差し替えとコードの拡張子修正は代わりに行います)。
